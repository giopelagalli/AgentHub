# AgentHub UI Tower Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Vite + TypeScript pixel-art SPA (`packages/ui`) rendering the hub as a six-floor top-down corporate tower with elevator navigation, always-on ambient animation, live node/agent/queue data over a new hub WebSocket, and streaming agent chat.

**Architecture:** Canvas layer (320×288 internal resolution, integer-scaled, 8fps animation tick on a 60fps rAF loop) for the world; DOM overlays for chat/queue/elevator/dialog panels. Procedural pixel art only (string-matrix sprites + palette lookup, no image assets). A single pub/sub store fed by `GET /api/state`, the new `/ws` WebSocket, and a 5s poll fallback. Hub gains `/ws` broadcast, per-tier `streams` in state, per-agent busy events, and static serving of `ui/dist`.

**Tech Stack:** Vite 6, TypeScript strict, vanilla DOM/canvas (no framework, no game engine), @fastify/websocket + @fastify/static in the hub, vitest (jsdom NOT required — logic modules are DOM-free by design).

**Authoritative design:** docs/superpowers/specs/2026-09-01-agenthub-ui-tower-design.md — floor table (§3), interaction model (§5), ambience requirements (§6) govern; this plan's tasks reference them.

## Global Constraints

- Monorepo conventions from Phase 1 hold: ESM everywhere, `.js` suffix on relative imports, TypeScript strict via tsconfig.base.json, tests under `packages/*/test/**/*.test.ts`, `npm test` green at every commit, commits conventional style ending with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- Canvas internal resolution exactly **320×288**; tile size **16px** (20×18 tiles); scale = `Math.max(1, Math.floor(min(winW/320, winH/288)))`, nearest-neighbor (`imageSmoothingEnabled = false`), canvas centered on a `#0f140f` page background.
- Animation tick: **8 ticks/second** derived from the rAF loop (accumulator), all sprite animation keyed to tick count, never to wall-clock per-frame.
- Palette lives ONLY in `packages/ui/src/art/palette.ts`; every color used anywhere in art modules must be a named palette entry. Base ramp names: `bg0 #0f140f, bg1 #1a231a, ink #202820, mid #4a5d4a, lit #8fae7a, pale #cfe0b8, cream #e8e4c8, accentRed #b4433a, accentBlue #3a6ab4, accentAmber #c9a13b` (art tasks may add entries, never inline hex).
- Sprite/tile format: `string[]` matrices, one char per pixel, `'.'` = transparent, other chars map to palette names via a per-sprite legend object. Validation helper (Task 2) enforces rectangularity and legend coverage; every art module gets a validation test.
- Floors are data: ordered `FLOORS` array (Task 2) with ids `b1 | f1 | f2 | f3 | f4 | ph`; display labels exactly: `B1 SERVER ROOM`, `1F LOBBY`, `2F GENERAL STAFF`, `3F SAMPLE PROJECT`, `4F VACANT`, `PH PENTHOUSE`.
- UI logic modules (store, elevator FSM, ws client, art data) must import nothing from DOM/canvas so vitest runs them in node. Rendering modules are excluded from unit tests; they are verified by the Task 6 browser walkthrough.
- WS protocol (shared package): `{type:'state', state: HubState}` and `{type:'agent-busy', agentId: number, busy: boolean}` — exact field names.
- Hub REST/WS changes must not break any existing Phase-1 test.

const nextMessage = (ws: WebSocket, pred: (m: any) => boolean, timeoutMs = 5000) =>
  new Promise<any>((resolve, reject) => {
    const t = setTimeout(() => reject(new Error('ws timeout')), timeoutMs);
    ws.addEventListener('message', (ev: MessageEvent) => {
      const m = JSON.parse(String(ev.data));
      if (pred(m)) { clearTimeout(t); resolve(m); }
    });

  it('sends state on connect and streams tier counters in /api/state', async () => {

    expect(first.state.streams).toEqual({ orchestrator: 0, worker: 0, vision: 0, 'video-gen': 0 });

    const ws = new WebSocket(wsUrl);
    await nextMessage(ws, (m) => m.type === 'state');

    const stateMsg = nextMessage(ws, (m) => m.type === 'state' && m.state.nodes.length === 1);

    await stateMsg;
    const agent = await (await fetch(`${base}/api/agents`, { method: 'POST', headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ name: 'a', tier: 'worker', systemPrompt: 's' }) })).json();
    const busyOn = nextMessage(ws, (m) => m.type === 'agent-busy' && m.agentId === agent.id && m.busy === true);
    const busyOff = nextMessage(ws, (m) => m.type === 'agent-busy' && m.agentId === agent.id && m.busy === false);
    await fetch(`${base}/api/agents/${agent.id}/messages`, { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify({ text: 'hi' }) });
    await busyOn; await busyOff;
    ws.close();
  });

// palette.ts
export const PALETTE: Record<string, string>; // the 10 Global-Constraint entries at minimum
// validate.ts
export interface SpriteDef { legend: Record<string, string>; rows: string[] } // legend char -> palette name
export function validateSprite(def: SpriteDef): void; // throws on ragged rows, unknown legend char in rows, legend value not in PALETTE
// floors.ts
export type FloorId = 'b1' | 'f1' | 'f2' | 'f3' | 'f4' | 'ph';
export interface FloorDef { id: FloorId; label: string; }
export const FLOORS: FloorDef[]; // order b1..ph, labels per Global Constraints
// store.ts
export interface UiState { hub: HubState | null; busy: Set<number>; floor: FloorId; connection: 'live' | 'polling' | 'down'; }
export type StoreEvent = { type: 'hub-state'; state: HubState } | { type: 'agent-busy'; agentId: number; busy: boolean } | { type: 'set-floor'; floor: FloorId } | { type: 'connection'; status: UiState['connection'] };
export class Store { getState(): UiState; dispatch(e: StoreEvent): void; subscribe(fn: (s: UiState) => void): () => void; }
// engine/loop.ts
export function startLoop(onTick: (tick: number) => void, onFrame: () => void): () => void; // rAF; onTick at 8/s via accumulator
// engine/screen.ts
export class Screen { readonly ctx: CanvasRenderingContext2D; constructor(host: HTMLElement); /* 320x288 backing canvas, integer scale, resize handling */ }
// engine/input.ts
export function bindPointer(canvas: HTMLCanvasElement, onClick: (x: number, y: number) => void): void; // maps client coords -> internal 320x288 coords
